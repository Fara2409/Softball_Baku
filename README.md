# Softball Baku — статистика игроков

Сайт статистики любительского софтбола в Баку: рейтинг игроков (performance score 0–10),
карточки игроков, протоколы игр и ссылки на ролики на YouTube.

Сайт: https://softball.az/

## Как устроены данные
- `data/players.json` — состав: имя, фамилия, номер, фото.
- `data/games/ГГГГ-ММ-ДД.json` — одна игра: счёт по иннингам и статистика каждого игрока.
- `data/index.json` — сезон и список игр.
- `players/` — фото игроков.

Рейтинг и сезонная статистика считаются на сайте автоматически из файлов игр.
